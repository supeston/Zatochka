### 😎 Че тут вообще под капотом:
- **Чистый CSS без всякого мусора** — выкинул весь тяжелый тайлвинд и жирные библиотеки, всё написано руками на чистом CSS. Весит 0 байт рантайма.
- **GPU-ускорение** — фон вынесен на видеокарту (`transform: translateZ(0)`), поэтому скролл плавный как масло даже на старом ксиоми брата.
- **Видосы не жрут трафик** — видео запускаются только когда до них долистаешь (`IntersectionObserver`), сами ролики пожаты на максимум.
- **Карта не крашит браузер** — темная карта грузится только когда надо, оперативку не жрет.
- **Адаптив** — открывай хоть с микроволновки, хоть с айфона, хоть с 4K моника — ничего не съезжает и не налазит.

---

### 🛠️ Как запустить у себя:
1. Качаешь репку:
```bash
git clone https://github.com/supeston/Zatochka.git
```
2. Просто два раза кликаешь по `index.html` и кайфуешь.
3. Никаких `npm install` на 2 гигабайта качать не надо, всё работает из коробки 🚀
