# Zаточка - Профессиональная заточка инструмента

Современный, ультра-оптимизированный лендинг для профессиональной мастерской по заточке инструментов «Zаточка». Проект создан с фокусом на максимальную плавность (60/120 FPS), стильный индустриальный дизайн и моментальный отклик на смартфонах и мобильных устройствах.

## 🚀 Особенности и оптимизация
- **Стек:** HTML5, чистый компилированный CSS3 с аппаратным GPU-ускорением, ленивая загрузка Leaflet (CartoDB Dark Matter), GSAP.
- **Нулевой оверхед (Zero Runtime Overhead):** Удалены тяжелые рантайм-компиляторы (Tailwind CDN) и сторонние шрифтовые библиотеки иконок (FontAwesome заменен на легковесные инлайн SVG).
- **Плавный скролл без просадок FPS:** Фиксированный фон вынесен в отдельный GPU-композитный слой (`transform: translateZ(0)`), предотвращающий перерисовку экрана при прокрутке.
- **Оптимизированное видео и постеры:** Ролики сжаты через H.264 с параметром `+faststart` для мгновенного потокового воспроизведения. Видео запускаются только при появлении на экране через `IntersectionObserver` с `preload="none"`.
- **Быстрая интерактивная карта:** Карта Leaflet загружается по требованию (on-demand) и использует нативные темные тайлы без тяжелых CSS-фильтров реального времени.
- **Адаптивность:** Идеальная работа и масштабируемость на любых экранах от мобильных телефонов до 4K-мониторов.
- **Статика:** Подготовлено для размещения на GitHub Pages прямо из корня репозитория.

## 💻 Разработка локально и деплой
1. Склонируйте репозиторий: `git clone https://github.com/supeston/Zatochka.git`
2. Откройте файл `index.html` в любом браузере двойным щелчком, либо используйте Live Server в редакторе кода.
3. Для деплоя на GitHub Pages достаточно залить файлы `index.html`, `style.css` и папку `videos/` в ветку `main` (Settings -> Pages -> Deploy from a branch -> `/ (root)`).
